Ranks 1.67M Medicare providers by how unusually they bill for their specialty,
using CMS Part B data 2019–2024 and OIG exclusion labels. XGBoost picked on a
locked ten-seed protocol, SHAP for explanations, and out-of-fold scoring so no
provider is ranked by a model that trained on them. Every flag states its reason
against the peer group; nothing identifying is published.
